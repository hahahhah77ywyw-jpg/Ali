# Omni Group Suite Web
نسخة Web محلية مستوحاة من واجهة الصور.
تشغيل سريع:
1. افتح index.html مباشرة في Chrome، أو استخدم أي خادم محلي.
2. لإظهار الموقع على 127.0.0.1:9091 استخدم خادمًا محليًا يربط المنفذ 9091 بالمجلد.
3. البيانات التجريبية محفوظة في LocalStorage.

ملاحظة: هذه النسخة واجهة وإدارة محلية فقط، ولا تتضمن تجاوز حظر WhatsApp أو التحايل على حدود المنصة.
